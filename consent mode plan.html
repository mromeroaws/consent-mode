Key technical advice

Five rules for the build
1Consent script→ 2HubSpot→ 3GTM / GA4 Required load order, so the first GA4 event carries the right consent state.

Keep region lists in sync

HubSpot decides which banner a visitor sees, but Google's script sets the default consent with its region parameter. The two country lists must be kept in sync by hand.

Guarantee load order

The consent script runs before HubSpot and GTM so the first GA4 event reflects the correct state.

Don't set gcs by hand

The Google tag adds this value automatically. The team only needs to confirm the consent state is right.

New editor: open questions Waiting on HubSpot

HubSpot still has to confirm whether banner types can differ by country, and how the listener behaves when a visitor rejects.

Don't migrate yet. Before pressing Switch to the new editor, take a screenshot of the current settings and wait for HubSpot to confirm the migration can be reversed.

Perficient: set consent on the page, let GTM follow

Perficient recommends setting Google Consent Mode in the page head from the HubSpot banner, with GTM reading that state. It builds on the gtag calls aws.org already has and corrects what caused the original problem in production. Details may shift with Legal's guidance, but the approach stays the same.

Three ways to build it

Perficient's options
Recommended

GTM + gtag consent scripts + CMP callback

Consent defaults and the HubSpot listener live in the page head. GTM reads the state. Builds on what aws.org already started.

Not chosen

Everything in GTM

Consent logic in a GTM consent template. Google leans toward templates, but it means rebuilding the HubSpot hookup in a container that UAT and production share.

Not chosen

Direct CMP integration

The consent platform talks to Google directly. Listed as the third common pattern.

Why this approach

Perficient POV

No timing gap

The denied default is set before GTM loads, so Google tags never fire without a consent state.

Follows HubSpot

HubSpot documents a gtag default and listener for Google Consent Mode. This builds on that.

Small GTM change

The GA4 All Pages tag stays as it is. Only tags that need consent get a trigger and a check.

Trade-off accepted: the consent code lives in the Sitecore page head, so any change to it goes through a site release.

Appendix: page head code (starting point) 
window.dataLayer = window.dataLayer || [];
function gtag(){dataLayer.push(arguments);}

gtag('consent', 'default', {
  'analytics_storage': 'denied',
  'ad_storage': 'denied',
  'ad_user_data': 'denied',
  'ad_personalization': 'denied',
  'region': [/* country codes per legal decision */],
  'wait_for_update': 500
});

var _hsp = window._hsp = window._hsp || [];
_hsp.push(['addPrivacyConsentListener', function(consent) {
  var analytics = consent && (consent.allowed || (consent.categories &&
    consent.categories.analytics));
  var ads = consent && (consent.allowed || (consent.categories &&
    consent.categories.advertisement));
  gtag('consent', 'update', {
    'analytics_storage': analytics ? 'granted' : 'denied',
    'ad_storage': ads ? 'granted' : 'denied',
    'ad_user_data': ads ? 'granted' : 'denied',
    'ad_personalization': ads ? 'granted' : 'denied'
  });
  gtag('event', 'hubspotConsentUpdate');
}]);

// Then the GTM head snippet, then the HubSpot embed (async)

How the estimate works

Method and assumptions

Traffic mix

Jan 4 – Sep 19, 2026, before the change: US 71%, Europe 3%, rest of world 26% of sessions. Engagement: US 73%, Europe 61%, rest 65%.

Opt-in loss, measured

While every region was opt-in, US sessions fell 43% after seasonality and Europe fell 51%. The model uses 50% for Europe.

Opt-out loss, assumed

With tracking on until a visitor declines, only visitors who actively opt out drop out. The model uses 5% (range 2–10%). The week of Oct 18 suggests losses may be smaller.

Not included

Traffic growth, campaigns, and GA4 behavioral modeling. Europe's volume (about 300 sessions a day) may be too small for modeling to switch on.

GA4 records about 75,500 sessions a week site-wide in 2026, about twice the 38,500 goal. The percentages are applied to the goal as given; the estimator's baseline slider applies them to any other baseline.

Questions for AWS Legal

Every vendor defers the final approach to Legal. These answers decide the region list, the defaults and the banner platform.

Which model applies in each region

  1. Which countries or regions require opt-in? Confirm the final list, including the EEA, UK and Switzerland 🇪🇺🇬🇧🇨🇭. HubSpot's privacy settings also list Canada and Brazil 🇨🇦🇧🇷: do they apply to AWS?
  2. In the US 🇺🇸, does any state law that applies to AWS require an opt-out, a "Do Not Sell or Share" link, or honoring Global Privacy Control (GPC)?HubSpot's banner is confirmed to target by country only, not by US state.
  3. Outside opt-in regions, is tracking on by default acceptable, with a notice and an option to decline?

Advanced Mode before consent

  1. Advanced Mode sends cookieless signals to Google before a visitor in an opt-in region answers the banner. Is that acceptable there?
  2. What should happen for visitors who never interact with the banner, in each region?
  3. Should returning visitors start as granted when the HubSpot consent cookie shows they already accepted?Raised by Perficient on Oct 30.

What "Reject" should mean

  1. When a visitor rejects, should all analytics tracking stop? Should existing Google Analytics cookies be deleted or just stop updating?
  2. Which categories (analytics storage, ad storage, ad user data, ad personalization) should be denied by default in each region?If AWS doesn't use Google Ads, denying the ad categories everywhere may be simplest.

Other tools on the site

  1. Which other scripts or vendors need consent before they run?

Text, records and policies

  1. Define the banner text for each region, and update the Cookie Policy and Privacy Policy to match the final setup.
  2. Decide whether visitors' consent choices must be recorded, and where.
  3. Decide whether the legal requirements favor HubSpot's banner or a dedicated platform such as CookieYes.If Legal needs targeting by US state or GPC support, that could decide the platform.
